# Backend-Integration Security Risk Register & Requirements — ClipCat

- **Assessment Date:** `2026-11-15`
- **Current State:** **No Python FastAPI backend and no compiled Tauri 2 native wrapper exist in this repository.** Every control below is **Unverified / Backend Work Required**.
- **Scope Rule:** Frontend validations (`src/utils/validation.ts`, `SettingsPage.tsx`, `desktop.ts`) provide **UX guidance only** and are trivially bypassed via `curl`, modified clients, or browser DevTools. The FastAPI backend and any desktop wrapper must enforce every boundary independently.

---

## ClipCat Frontend-to-Future-Backend Threat Model Snapshot

- **Assets:** Uploaded source videos, downloaded media URLs, filenames, project names, Whisper speech transcripts, captions, clip trim/export metadata, OS storage directory settings (`projectDirectory`, `exportDirectory`, `tempDirectory`), exported MP4/SRT/VTT/JSON/ZIP archives, API credentials (when introduced), and host localhost/LAN services.
- **Entry Points (Implemented Frontend -> Future Backend):**
  - **Implemented Now:** Browser forms (`NewProjectPage`, `SettingsPage`, `ClipEditorPage`, `ProjectsPage`), drag-and-drop/file picker (`POST /api/projects/upload`), URL input (`POST /api/projects/from-url`), query strings (`?mock=1`, `/projects/new?mode=url`), `localStorage` (`clipcat-ui-preferences`, `clipcat-api-base-url`).
  - **Planned Future Flows (Unimplemented):** FastAPI REST handlers (`/api/projects*`, `/api/clips*`, `/api/jobs*`, `/api/settings*`, `/api/system*`), FFmpeg/Whisper subprocess runners, URL downloader worker, ZIP archiver, SQLite/DB persistence, and Tauri 2 IPC commands (`open_output_folder`).
- **Trust Boundaries:**
  1. Untrusted web origin / malicious webpages <-> Local FastAPI (`127.0.0.1:8000` or LAN `192.168.x.x:8000`).
  2. Browser UI / `localStorage` <-> FastAPI JSON/multipart handlers.
  3. FastAPI server <-> Host OS filesystem (`storage.*` paths) & external internet (`from-url`).
  4. FastAPI server <-> FFmpeg / AI transcription subprocesses.
- **Threat Actors:** Malicious media containers/metadata, SSRF-crafted URLs, hostile websites in the user's browser attempting cross-origin requests to localhost/LAN port `8000` ("localhost-by-browser" attacks), untrusted project imports, compromised packages, and local user-space processes.

## Phase 1: Mandatory Blockers BEFORE Connecting FastAPI Locally / Over LAN

Even single-user localhost or LAN operation (`http://192.168.x.x:8000` recommended in `SettingsPage.tsx:552`) exposes the user's machine to malicious browser tabs and LAN peers if the following controls are not enforced first:

| # | Control Area | Requirement & Why It Matters | Responsible Component | Verification / Test Method | Acceptance Evidence Required |
|---|---|---|---|---|---|
| **1** | **Local API Binding & Hostile-Website Protection** | Bind uvicorn strictly to `127.0.0.1` by default (`0.0.0.0` only on explicit LAN opt-in). Require a per-install/session bearer token (`X-ClipCat-Token` or `Authorization: Bearer`) paired with strict CORS origin validation so any hostile webpage open in the user's browser cannot send silent `fetch`/`POST` requests to `127.0.0.1:8000` to delete projects, clear temp files, trigger downloads, or read transcripts. | FastAPI startup config + Auth Middleware | Inspect bind args; replay `curl` & cross-origin browser `fetch` from `http://evil.example` without token | Rejected with `401`/`403`; zero `*` wildcard CORS headers. |
| **2** | **CORS Allowlist & Origin Policy** | Allowlist exact frontend origins (`http://localhost:3000`, `tauri://localhost`, configured domain). Reject `Origin: null` and wildcard `*` + credentials. | FastAPI `CORSMiddleware` | Send `Origin: https://evil.example` preflight `OPTIONS` & `GET/POST` requests | No `Access-Control-Allow-Origin` echoed for untrusted origins. |
| **3** | **CSRF Protections** | If cookie authentication is ever introduced, enforce `SameSite=Lax/Strict`, custom CSRF tokens, and `Origin`/`Referer` checks on all state-changing `POST`/`PATCH`/`DELETE` routes. If header-only bearer tokens are used (not cookies), document stateless CSRF resistance. | FastAPI Auth / CSRF Middleware | Replay `POST /api/settings` / `DELETE /api/projects/{id}` cross-site without token | Request rejected `403 Forbidden`. |
| **4** | **Input Schemas & Validation** | Enforce strict Pydantic v2 models with bounded string lengths, enums (`aspectRatio`, `layoutMode`, `resolution`, `outputFormat`), positive finite numeric bounds (`startSec < endSec`), and unknown-field rejection (`extra="forbid"`). Frontend `validation.ts` checks are trivially bypassed. | FastAPI Pydantic routers | Send malformed types, negative durations, 1 MB strings, extra keys | Strict `422 Unprocessable Entity` without stack traces. |
| **5** | **URL Fetching Protections & SSRF Prevention** (`CC-FE-003`) | Never rely on `classifyAndValidateVideoUrl`. Resolve DNS explicitly in Python (`socket.getaddrinfo`), block loopback (`127.0.0.0/8`, `::1`), RFC1918, link-local/cloud metadata (`169.254.0.0/16`, `fe80::/10`), multicast/reserved IPs; allow only ports `80`/`443` and `http`/`https`; disable or re-validate HTTP redirects on every hop; stream with byte cap + socket timeout; reject embedded credentials. | FastAPI URL Downloader Worker | Unit/integration test with `127.0.0.1`, `169.254.169.254`, `[::1]`, `302` redirect to `127.0.0.1` | All internal/redirect probes blocked prior to TCP connect. |
| **6** | **File Signature / Content Validation & Upload Limits** (`CC-FE-002`) | Stream uploads with enforced max `Content-Length` / chunk byte counter (`<= 8 GB` or configured cap); ignore client `file.type` & raw filename extension alone; inspect magic bytes / container headers via `libmagic` + `ffprobe` strictly validating MP4/MOV/MKV/WebM streams before processing. | FastAPI `/api/projects/upload` | Upload HTML/EXE/ZIP renamed to `.mp4` and oversized stream | Rejected `415`/`413` prior to disk retention or FFmpeg execution. |
| **7** | **Safe Filenames & Storage Isolation (Path Traversal Defense)** (`CC-FE-GAP-004`) | Ignore user/metadata filenames for disk storage paths; generate UUIDv4 internal filenames (`{project_id}/{uuid}.mp4`). Validate `settings.storage.*` directories (`projectDirectory`, `exportDirectory`, `tempDirectory`) against an explicit OS base-directory allowlist (`Path.resolve().is_relative_to(ALLOWED_ROOT)`), blocking arbitrary writes/deletes like `C:\Windows` or `/etc` (`Clear Temporary Files`!). | FastAPI Storage / Settings Service | Attempt `tempDirectory: "/"` + `POST /api/system/clear-temp` and upload `../../evil.mp4` | Path outside allowlist rejected `400/403`; UUID names stored cleanly. |
| **8** | **Media Processing Sandboxing & Resource Limits** | Invoke `ffmpeg`/`ffprobe`/Whisper strictly via `subprocess.run([...], shell=False)` with `--` argument termination; disable external FFmpeg playlist/protocol demuxers (`-protocol_whitelist file,pipe`); apply memory (`RLIMIT_AS`), CPU, temp-disk quota, and wall-clock timeouts (`timeout=...`) per job so malformed video headers cannot RCE or exhaust host RAM/disk. | FastAPI Job Worker / FFmpeg Wrapper | Run malformed/polyglot container & HLS `.m3u8` file-read payload against worker | Malformed file fails gracefully with bounded timeout; `-protocol_whitelist` prevents local file reads. |
| **9** | **Safe Errors & Structured Logging** | Return sanitized error JSON (`{ "detail": "..." }`) conforming to `src/api/errors.ts`; never leak Python tracebacks, SQL errors, OS paths, or environment variables in HTTP 500 responses; scrub newlines/control chars from log fields (log injection). | FastAPI Global Exception Handler | Trigger intentional `ValueError` / missing file / DB constraint error | Generic `500` JSON returned; stack trace written only to local server logs. |
| **10** | **Export / Download Security (`Content-Disposition` & Origin Lock)** (`CC-FE-006`) | Return strictly relative API paths (`/api/clips/{id}/download`, `/api/exports/{archive_id}.zip`) canonicalized inside export storage root, served with `X-Content-Type-Options: nosniff` and safe RFC 6266 `Content-Disposition: attachment; filename="..."` sanitized against newlines/quotes/slashes. | FastAPI Export / Static Download Router | Request export download with `../` IDs and inspect HTTP headers | `404`/`400` on traversal; `nosniff` and `attachment` headers present. |
| **11** | **Desktop IPC / Filesystem Permissions (If Tauri 2 Added)** | Scope Tauri capabilities strictly (`capabilities/default.json`); validate `open_output_folder` directory path in Rust using canonicalization + containment inside configured ClipCat export root; disable `shell:allow-open` on arbitrary URLs/paths; enforce strict Tauri CSP matching bundled assets. | Tauri 2 Rust Core & Capabilities | Code audit of `src-tauri/` + capability JSON + runtime IPC test (`../../` arg) | Rust rejects paths outside ClipCat export root. |

## Phase 2: Mandatory Blockers BEFORE External / Multi-User / Public Internet Release

In addition to all Phase 1 items, **none** of the following controls exist yet and **all** are mandatory before multi-user, internet-hosted, or shared-workspace deployment:

| # | Control Area | Requirement & Why It Matters | Responsible Component | Verification / Test Method | Acceptance Evidence Required |
|---|---|---|---|---|---|
| **12** | **Authentication & Session Lifecycle** (`CC-FE-GAP-003`) | Implement verified identity authentication (e.g., OAuth2/OIDC or Argon2id password + short-lived signed JWT or HttpOnly/Secure/SameSite cookie sessions with rotation & revocation). | Auth Service + Frontend Auth Flow | Automated integration tests for login, expiry, invalid/tampered tokens, logout revocation | Unauthenticated requests to `/api/*` fail `401`. |
| **13** | **Server-Side Authorization & Project/Job/Export Ownership** | Scope every project, clip, job, cancellation, and download query by authenticated `owner_id` (prevent IDOR across `/api/projects/{id}`, `/api/clips/{id}`, `/api/jobs/{id}/cancel`, `/api/clips/batch-export`). | FastAPI Authorization Dependencies + DB Queries | Cross-account horizontal IDOR test (User B requests/cancels/downloads User A's IDs) | Every endpoint returns `403` or `404` for non-owners. |
| **14** | **Job Isolation, Cancellation & Concurrency Quotas** | Enforce per-user concurrent processing job limits, isolated temporary working directories per job (`temp_root/user_id/job_id`), and strict ownership checks on `/api/jobs/{id}/cancel`. | Job Scheduler / Queue | Submit parallel jobs exceeding quota; cancel another user's job | Excess jobs queued/rejected (`429`); unauthorized cancel blocked (`403`). |
| **15** | **TLS & Security Headers** (`CC-FE-GAP-002`) | Enforce HTTPS/TLS 1.2+ (HSTS on public domains) when leaving `127.0.0.1` (blocking plaintext `http://192.168.x.x` credential transmission over shared Wi-Fi). Deploy `Content-Security-Policy` (without `unsafe-inline` scripts), `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY` / `frame-ancestors 'none'`, `Referrer-Policy: no-referrer`, and restrictive `Permissions-Policy`. | Reverse Proxy / Hosting (`vercel.json` / Nginx / Caddy) + Vite Build | `curl -sSI` against deployed staging/prod HTTPS origin & CSP Evaluator | All headers verified present; TLS enforced (`301` HTTPS redirect + HSTS). |
| **16** | **Rate Limiting & Abuse Controls** | Apply per-IP and per-user rate limits on auth, upload, URL-import, and heavy AI re-render endpoints (`POST /api/clips/{id}/render`, `POST /api/projects/from-url`, `/api/clips/batch-export`) to prevent CPU/GPU/bandwidth exhaustion. | API Gateway / FastAPI `slowapi` or Redis limiter | Automated burst request test | Returns `429 Too Many Requests` with `Retry-After`. |
| **17** | **Database Access Controls & Parameterized Queries** | Use SQLAlchemy/SQLModel ORM or strictly bound SQL parameters for all queries; never string-format user titles, queries, or sort columns directly into raw SQL; isolate least-privilege DB credentials. | FastAPI Persistence Layer | SAST (`bandit`/`semgrep`) + SQLi payload tests in search/sort/title fields | Zero string-interpolated SQL; payloads stored verbatim. |
| **18** | **Secrets Management** | Load signing keys/DB credentials/third-party keys exclusively from OS secrets manager or server environment variables (never `.env` committed to git or `VITE_*` browser variables). Document rotation procedure. | Backend Deployment / Ops | Secret scan of repo & built artifacts + runtime env check | Zero secrets in frontend bundle or source tree. |
| **19** | **Dependency & Runtime Security Hygiene** (`CC-FE-GAP-001`) | Pin Python (`requirements.txt` / `uv.lock`) and Node (`package-lock.json` / `bun.lock`) dependencies, run automated `pip-audit` + `npm audit` + `bandit` in CI, use non-root OS user for backend/worker containers, and remove unused packages (`express`, `@google/genai`, `dotenv`). | CI/CD Pipeline & Container Runtime | Inspect CI workflow & container `USER` | Automated audits pass; worker runs non-root. |
| **20** | **Backup, Deletion, Retention & Privacy Behaviour** | Enforce hard deletion on `DELETE /api/projects/{id}` and `/api/clips/{id}` (cascading source videos, extracted WAVs, transcripts, rendered MP4s, thumbnails, and DB rows), implement automated TTL cleanup for failed/orphaned temp jobs, and keep privacy disclosures (`SettingsPage.tsx:726-731`) strictly accurate to actual data flows. | Storage Cleanup Cron + Privacy Docs | Delete a project and inspect filesystem + DB | Zero orphaned source/transcript files remain on disk; retention documented. |
