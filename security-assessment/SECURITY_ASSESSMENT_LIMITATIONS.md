# Security Assessment Limitations Register — ClipCat Pre-Backend Frontend

- **Assessment Date:** `2026-11-15`
- **Repository Scope Evaluated:** ClipCat Frontend (`/app/applet`) ONLY.
- **Mandatory Assurance Notice:** Every untested control below remains **Unverified**. Passing frontend checks, clean `tsc`/`vite build`, or clean `bun audit` output do **not** provide assurance over backend, desktop native, or production hosting security.

---

## Untested, Blocked, & Partially Tested Areas

| Area | Status | Reason Not Tested / Blocked | Access or Environment Needed to Test | Remaining Risk |
|---|---|---|---|---|
| **1. Python FastAPI Backend & Processing Pipeline** | `NOT TESTABLE` | Backend repository/service is not present or connected to this frontend. | Complete FastAPI codebase (`app/main.py`, routers, Pydantic schemas, SQLite/DB layer, FFmpeg/Whisper worker code) running in an isolated test environment. | High — Server-side auth, CORS, CSRF, SSRF mitigation, magic-byte validation, path-jail enforcement on `storage.*`, FFmpeg argument/demuxer sandboxing, SQL parameterization, and rate limiting are completely unverified. |
| **2. Live Backend CORS, Response Headers, & Real File Upload Streaming** | `NOT TESTABLE` | No FastAPI API server exists to accept multipart uploads (`<= 8 GB`), `from-url`, download `HEAD` requests, or CORS preflights. | Live FastAPI backend instance bound to test host/port. | High — Cross-origin browser attacks against localhost/LAN port `8000` ("localhost-by-browser" CSRF/fetch) and streaming resource exhaustion cannot be evaluated. |
| **3. Multi-Gigabyte Upload Memory Pressure & Real Media Decoding** | `NOT RUN` (Beyond small blob tests) | Dynamically testing near-8 GB file buffers or corrupt H.264/HEVC streams inside headless sandbox browser risks container OOM/DoS (prohibited by Section 2 safety rules). | Dedicated local performance/fuzzing test harness with bounded sample containers (e.g., 100 MB–2 GB fixtures). | Medium — Browser tab crash/OOM risk when loading `URL.createObjectURL(file)` metadata for multi-GB videos remains unmeasured. |
| **4. Tauri 2 Desktop Wrapper (`src-tauri/`)** | `NOT APPLICABLE` / `NOT TESTABLE` | No `src-tauri/` directory, `tauri.conf.json`, Rust backend, or capability files exist in the repository—only `src/utils/desktop.ts` browser detection stubs. | Complete Tauri 2 workspace (`src-tauri/src/*`, `capabilities/*.json`, `tauri.conf.json`) and Windows desktop build. | High (when packaged) — Native IPC `open_output_folder` command scoping, desktop filesystem permissions, Tauri CSP, and custom protocol isolation are unverified. |
| **5. Production Hosting Security Headers & TLS Configuration** | `NOT TESTABLE` (Partial local header check only) | No `vercel.json`, `nginx.conf`, or cloud reverse-proxy configuration exists in the repo; `localhost:3000` runs Vite dev HTTP server (which emits zero security headers). | Staging/production hosting config and deployed HTTPS endpoint. | Medium — Production `Content-Security-Policy`, HSTS, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, and `nosniff` enforcement depend entirely on future deployment setup. |
| **6. `npm audit` & Git Commit History Secret Scanning** | `BLOCKED` / Workaround Used | `npm audit --json` exited `1` (`ENOLOCK`) because `package-lock.json` is absent (`bun.lock` used instead; `bun audit` ran instead). `.git` directory does not exist in `/app/applet`. | `package-lock.json` generated via `npm i --package-lock-only` and access to full `.git` repository history. | Low–Medium — Historical commits could hold removed credentials or prior assets unseen in the current snapshot; `npm` tooling consistency fails cleanly until aligned. |
| **7. Dedicated External SAST / Semgrep / CodeQL Rulesets** | `NOT RUN` | Neither `semgrep` nor `codeql` CLI tools are installed in the sandbox environment (and proprietary code cannot be uploaded to external cloud scanners per Section 7). | Local Semgrep/CodeQL CLI installation in CI/CD. | Low — Manual + `grep` static review inspected all security-relevant files directly, though deep taint tracking across future modules should use CI SAST. |
| **8. Live Service Detected on Sandbox `127.0.0.1:8000`** | `EXCLUDED` (Out of Scope) | Initial probe revealed an unrelated sandbox container service listening on `127.0.0.1:8000` returning HTTP `401` without CORS headers. Per Engagement Section 2 ("Out of scope: Attacking unrelated localhost services"), probing port `8000` was stopped immediately. | Dedicated local ClipCat FastAPI instance on an isolated test port. | Low in assessment (explicitly avoided); highlights real-world port-collision hazard captured in `CC-FE-007`. |
